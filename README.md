# GHOSTERS — refined editorial website

A fresh responsive website package, separate from your existing live website.

## Preview
1. Extract the ZIP to a new folder.
2. Double-click `index.html` to open it in a browser.
3. Internet access loads the optional fonts.

## What's included
- Your supplied logo (if included in the download session)
- Six cover-art images and story descriptions for literary fiction, romance, thriller/mystery, self-help, children's books, and fantasy
- Responsive portfolio, services, studio, and contact sections
- Contact email: info.ghosterspublishing@gmail.com

The sample books are fictional creative concepts, not published client projects. This is a static marketing website; user accounts, private messaging, member management, and profile verification require a backend or integrated service.

Keep your old live website unchanged until you approve this version.
